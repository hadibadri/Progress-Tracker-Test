# Pomegranate — progress tracker redesign

Patient app prototype for a GLP-1 weight-management programme.

Open `pomegranate-app.html` in a browser (phone-width window, or desktop with the reviewer panel).
Jump to a demo state with a hash, e.g. `#dose`, `#return`, `#replied`, or long-press the wordmark for the demo menu.

- `pomegranate-app.html` — the redesigned app
- `assets/` — images, line art, wordmark and `CREDITS.md`
- `pomegranate-redesign-notes.md` — design rationale, retention research, closed loop, return-after-absence, motion spec
- `screenshots/` — every screen at 320×568, 375×667, 393×852 and desktop; `motion/` holds animation frame sheets
- `backup/` — the previous version of the app
- `research/` — the progress tracker research report
- `references/` — art-direction references
